# VulnAgent - AI-Based Vulnerability Assessment and Prioritization Agent

## Overview
VulnAgent is an AI-powered cybersecurity assistant developed using Python, LangChain and Groq.

It helps users analyze cybersecurity vulnerability descriptions, understand potential security risks, and prioritize vulnerabilities based on severity and CVSS scores.

## Day 2 Implementation

- Structured prompt engineering
- Role, Facts, Rules and Format prompting
- Few-shot prompting
- JSON response generation
- JSON response parsing using `json.loads()`
- Vulnerability prioritization
- Conversation memory
- Interactive vulnerability analysis
- Error handling and logging
