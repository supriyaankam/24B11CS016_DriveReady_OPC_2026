# VulnAgent - AI-Based Vulnerability Assessment and Prioritization Agent

## Overview
VulnAgent is an AI-powered cybersecurity assistant developed using Python, LangChain and Groq.

It helps users understand cybersecurity vulnerabilities, analyze potential security risks, and prioritize vulnerabilities based on severity and CVSS scores.

## Day 1 Implementation

- Groq LLM integration
- Cybersecurity system prompt
- Vulnerability analysis function
- Severity and CVSS-based prioritization
- Prompt Guard integration
- Basic malicious prompt screening

## Technologies Used
