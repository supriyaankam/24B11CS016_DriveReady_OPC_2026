# VulnAgent - AI-Based Vulnerability Assessment and Prioritization Agent

## Overview
VulnAgent is an AI-powered cybersecurity assistant developed using Python, LangChain and Groq.

It helps users understand cybersecurity vulnerabilities, analyze potential security risks, and identify potentially malicious prompts using AI.

## Day 1 Implementation

- Groq LLM integration using LangChain
- Cybersecurity system prompt
- Vulnerability question-answering function
- Basic vulnerability analysis
- Prompt Guard integration
- Malicious prompt screening
- Severity and CVSS-based vulnerability prioritization
